Fault Ticket Dashboard

Full-featured dashboard with CSV upload, cloud sync for field teams, detailed ticket table, alarm severity indicators, filtering by 8 categories, and print support. Works on mobile and desktop.

Launch Dashboard

🚀 How It Works

Step 1: Open the dashboard and upload your CSV ticket export file, or let it auto-load the latest data from the cloud.

Step 2: Use the "Update Cloud for Field" button to push data so field technicians automatically receive the latest tickets.

Key Features

✓ Cloud Sync - Push data once, field teams auto-load it

✓ Alarm Indicators - Visual bulbs show critical pending issues

✓ Responsive Design - Works on mobile and desktop

✓ Click to Call - Direct calling from ticket contacts

✓ Smart Filtering - Filter by 8 ticket categories

✓ No Database Needed - Uses browser storage + JSONBin cloud

📌 Quick Tips

🔹 First Time? Upload a CSV file in the dashboard to get started.

🔹 Share with Field: After uploading, click "Update Cloud for Field" so technicians get the latest tickets automatically.

🔹 Check Timestamp: Look at the "Cloud Updated" timestamp in the dashboard to verify you have the latest data.
